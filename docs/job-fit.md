# AI 数据工程岗位能力对应

本项目重点展示 Python 数据处理、LLM 接口集成、对话数据质量和可复现检查。它适合 AI 数据工程实习方向，但不能替代 SQL、数据库和数仓基础。

以下以智能思创官方招聘页中涉及 AI 数据流程的实习职责为参考，而非将项目描述为该公司的实际业务。[官方岗位说明](https://www.aistrong.com/join.html)（2026 年 10 月 29 日访问）。岗位名称为“大模型算法实习生”，其中职责包含 AI 数据处理、数据工具开发、质量核验与 AI 辅助开发，适合用于能力拆解。

| 岗位关注的能力 | 本仓库可检查的证据 | 当前边界 |
| --- | --- | --- |
| Python / JSON 数据处理 | schema、pipeline 与人工异常样例 | 本地文件批处理，无大规模性能验证 |
| 数据清洗与质量控制 | 角色顺序、空值、完整轮次、脱敏、去重及拒收报告 | 规则检查，不是语义正确性评测 |
| LLM API 与 Prompt | 角色提示词、多轮上下文、流式协议适配 | 无微调、RAG 或工具型 Agent |
| 数据流程与可追溯性 | 内容哈希、处理配置、会话级划分、输出哈希 | 无调度平台和数据库血缘系统 |
| AI 辅助开发与验证 | 原型演进记录、正常与异常路径测试 | 面试需能够亲自讲解、修改与运行 |
| SQL 与关系型数据库 | 本仓库未实现 | 用 Olist / 数仓项目补充展示 |

## 可使用的简历表述

项目名称：AI 智能伴侣与对话数据处理

技术：Python、Streamlit、LLM 兼容 API、JSON / JSONL、pytest、GitHub Actions

- 基于已有 AI 伴侣原型，借助 AI 编程工具完成模块化整理，实现角色配置、多轮流式对话与本地会话管理，支持通过环境变量切换模型服务。
- 构建对话数据准备流程，兼容旧版 JSON，完成结构与轮次校验、规则脱敏、会话去重和 SFT 风格 JSONL 导出；按会话哈希划分数据，并输出质量统计及来源追踪记录。
- 使用人工构造的异常样例及本地流式接口模拟，验证数据规则、会话管理与失败回退行为，配置自动化检查流程。

此处不附虚构业务效果。8 份人工样例的计数只用于解释验证方法，不应表述为真实用户规模；SFT 风格样例导出也不等于已经完成模型微调。首次开发月份应由作者依据真实记录填写，不根据整理日期倒推。
